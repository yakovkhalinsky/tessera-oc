## Scope (Yakov's p1d: four small follow-ups to phase 1c)
The patch makes these edits; you only apply it.
* (a) `firmware/oc_ui.cpp`, `ui_start()`: `ui_timer.priority(UI_SAMPLE_PRIORITY)` now comes before `ui_timer.begin(ui_sample, UI_SAMPLE_US)`, so the channel never starts at the framework's default priority. The comment above `#define UI_SAMPLE_PRIORITY` says how the Teensy 4 runs it (all IntervalTimers share the PIT's one interrupt, at the highest priority asked for, the tick's 80); the file's head comment and the sampler's comment no longer say "below the tick".
* (b) `parts/oc_ui_input.h`, `ui_ring_t`: a new `volatile uint32_t dropped`; `parts/oc_ui_input.c`, `ui_ring_put`: a sample that finds the ring full counts `r->dropped++` (its detents stay in the carry, as before). `tests/oc_ui_test.c`, `check_ring`: 2 checks (ring1 drops nothing; ring2 counts 36), so oc_ui goes from 51 to 53. `firmware/oc_ui.cpp`, `draw_info`: line 1 is `v<version> STORE RO|OFF`, line 6 is `DROP EV <queue drops> RING <ring drops>`. `docs/img/screen-info.png` changes (drawn in step 3); `docs/GUIDE.md`, INFO and the sampler's sentence, say so.
* (c) `docs/UI-PLAN.md` §3.4, after "Pin modes untouched": the note **"Note (p1d): 1 kHz polling is fine for the detented encoders."**
* `CHANGELOG.md`: one phase 1d section.
* (d) `docs/STATUS.md`: already done in the ops commit (1c merged, 1d in progress); the 1d row's result at the end (step 6), in its own commit.
* Nothing else: 0 lines in `.github/`, `vendor/`, `docs/briefs/`, the engine (`firmware/oc_engine.c`), `firmware/oc_platform.cpp`, `firmware/oc_port.h`.
